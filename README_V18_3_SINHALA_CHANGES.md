# LankaAlert V18.3 — සිංහල වෙනස්කම්

මෙම release එකේ code comments සිංහලෙන් දමා ඇති ප්‍රධාන වෙනස්කම්:

- LankaAlert logo එක කිහිප වතාවක් ඔබන admin access ක්‍රමය ඉවත් කර ඇත.
- Header එකේ එකම search bar එකෙන් `Lanm` ඇතුළත් කළ විට Admin Access panel එක විවෘත වේ.
- Search results/list, Home connection ribbon, Home new-report shortcut, Nearby Reports, Live Alerts සහ අනවශ්‍ය privacy link සඟවා ඇත.
- Local Forecast එකේ උෂ්ණත්වය, වර්ෂාපතනය, වැසි සම්භාවිතාව, ආර්ද්‍රතාව, සුළඟ, අහසේ ස්වභාවය සහ API මඟින් ලැබෙන AQI පමණක් පෙන්වයි. Rain timing card එක ඉවත් කර ඇත.
- Local Forecast එකට ශ්‍රී ලංකා public river-gauge API එකෙන් ගංගා ජල මට්ටම එකතු කර ඇත. API එකේ reading එක නොමැති නම් `—` පෙන්වයි.
- Home guest banner එකේ පණිවිඩය `Please sign in to view or submit the alert and report.` පමණි. Area එක වෙනස් කිරීමට search field එකක් නැති අතර `Change` button එක පමණක් ඇත.
- Weather Live Conditions සඳහා නිවී-පත්තු වන රතු dot එකත් Map Live Map සඳහා රතු live indicator එකත් එක් කර ඇත.
- Alert badge එක unread alerts ගණන පෙන්වයි; Alerts tab එක බැලූ පසු badge එක clear වේ.
- Desktop Settings view එක account/profile center layout එකකට සකසා ඇත.
- Light/Dark theme වෙනස් කිරීමේදී scroll position එක තබා ගනී.
