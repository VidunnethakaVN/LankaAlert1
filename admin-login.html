LankaAlert Admin

Restricted to Disaster Management Centre / district officials. This portal is intentionally separate from the citizen Google sign-in — your Firebase account must also have an admins/<uid> document before access is granted.

Firebase UID — copy this ID

Paste this UID into Firestore → admins as the document ID. Keep this page open until you copy it.

First time setup / create admin account

Creating an account here only makes a Firebase Auth user. It will not be able to see the admin dashboard until a project owner manually adds a matching document to the admins collection in Firestore. See SETUP.md → "Creating your first admin".
