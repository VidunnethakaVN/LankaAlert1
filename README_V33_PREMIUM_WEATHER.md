# LankaAlert V33 — Premium Weather Dashboard

- Dashboard now shows current temperature, wind, humidity, forecast rainfall for the next 24h and next 72h, plus nearby river level when available.
- Forecast precipitation is calculated from Open-Meteo hourly precipitation values.
- Legacy horizontal/ticker-style text effects are neutralized and dashboard microcopy is given cleaner wrapping and spacing.
- Removed the visible dashboard checklist card while keeping other emergency tools.
- Existing GPS, reports, alerts, map, profile and Firebase flows are preserved.

Note: Open-Meteo documents its free API as non-commercial. For a commercial launch, use a licensed plan or a self-hosted Open-Meteo instance.
